자율주행 수업 자동차의 Blender 설계, 출력 검토 파일, 조립 안내와 작업 기록입니다.

## 최신 설계

- 최신 통합 모델: [배터리 탈착 v4.2](models/assembly-v3/20261029_자율주행자동차_배터리탈착_v4.2_A.blend)
- [배터리 탈착 안내](outputs/20261029_battery_service_v4_2_A/20261029_배터리탈착_안내_v4.2_A.html)
- [카메라 클립 안내](outputs/20261029_camera_clip_v4_1_A/20261029_카메라클립_조립안내_v4.1_A.html)
- [진행 상태](PROJECT_STATUS.md), [설계 검토](DESIGN_CHECKLIST.md), [AI 활용 기록](AI_WORK_LOG.md)

**출력 확정본이 아닙니다.** 카메라/센서 체결, 실제 배선, 바퀴 주행, 슬라이싱 등 남은 항목은 상태 문서를 확인하세요. 버전별 STL은 변경분을 포함하므로 서로 임의로 섞어 출력하지 마세요.

## 폴더와 원본 보존

- `references/`: 수업 지급 자료와 원본 부품 STL. 크기와 형상을 변경하지 않습니다.
- `models/`: 버전별 Blender 모델과 생성/검사 스크립트.
- `outputs/`: 렌더, 검토용 STL, 조립 안내와 검사 결과.
- 과거 버전은 이력 보존용이며 최신 설계와 구분합니다.

## 다른 컴퓨터에서 받기

`.blend`, `.stl`, `.zip`은 Git LFS로 관리합니다. Git LFS가 준비된 환경에서 저장소를 복제한 뒤 `git lfs pull`로 실제 대용량 파일을 받으세요. LFS 포인터만 받은 상태에서는 Blender 모델을 열 수 없습니다.

임시 폴더, Blender 자동 백업(`.blend1` 등), 실행 로그와 비밀정보용 환경 파일은 업로드에서 제외합니다. HTML 안내는 로컬에서 열어 보세요.
