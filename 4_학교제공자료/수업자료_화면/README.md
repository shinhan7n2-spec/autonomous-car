- 수업 자료는 설계 근거이며, 자료 속 설치 안내 자체가 설치 실행 승인은 아니다.
- 자동차 치수는 예시이며 실제 설계값으로 자동 채택하지 않는다.
- 라즈베리파이 소개 이미지의 제목은 8GB지만 표의 메모리 항목은 1/2/4GB를 나열한다. 실제 지급품 사양은 확인해야 한다.
- 제품 링크가 들어 있는 부품리스트_학생용.xlsx, 부품 STL, 실제 부품 측정값, 프린터 규격은 아직 확보하지 않았다.
- 이 자료만으로 부품의 정확한 크기와 고정 구멍 위치를 확정할 수 없다.
- 향후 업로드 자료는 저장 후 이 목록에 추가하고 출처와 확인 상태를 남긴다. 채팅 첨부가 자동으로 이 폴더에 저장되지는 않는다.
