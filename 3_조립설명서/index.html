5 주의

  • 도로 폭: 차 폭 28.3cm, 도로 30cm. 한쪽 여유 8mm

v6.3덮개가 얹기만 해서 주행 중 들릴 수 있음. 실제 웹캠 클립은 위판이 길고 뒤판이 비스듬히 내려옴(사진)기둥을 덮개 천장까지 올려 M6 1개로 덮개+선반 고정. 카메라 받침 뒤 틈 삭제, 덮개 천장 구멍 뒤로 넓힘해결 간섭 0건, 볼트 풀면 들어 올림 걸림 0건
v6키트에 볼트가 부족할 수 있음. 덮개 핀이 부러지기 쉬움. 부품이 많음키트 볼트만 사용(출력물에 직접 나사). 덮개 핀 → 테두리 턱. 지지대·고정편 → 출력 기둥·레일. 모터 받침·하판 좌우 일체해결 20개 → 10개
v5.3배터리를 뺄 때마다 볼트 4개를 풀어야 함. 모터 볼트 머리가 배터리 밑에 깔림. 보조배터리가 덮개 뒤 다리에 걸림잠금판을 홈에 꽂는 방식으로. 바닥판에 볼트 머리 홈. 덮개 다리 2mm 줄임해결 빼는 길 간섭 0건
v5.2작은 출력 부품이 너무 많음 (21개)가로대 2개를 1개로. 고정편 8개는 막대로 합치면 드라이버 단자·파이 핀을 덮고, 잠금판을 합치면 충전 때 볼트 4개를 풀어야 해서 유지해결 20개
v5.2선반 뒤쪽 지지대 구멍이 판 끝에서 1mm라 뒤가 트인 U자 홈이 됨. 선반이 뒤로 밀릴 수 있음구멍 주변에 판을 덧대 막힌 구멍으로해결
v5.2예전 버전 흔적: 옛 센서 받침 턱·가이드, 옮기기 전 지지대 구멍 2곳, 가려진 케이블 타이 구멍, 옛 캐스터 구멍 끝삭제하거나 메움. 남긴 구조는 모두 구조 지도에 용도를 적음해결
v5.2선반 아래 보강대 때문에 판 전체가 공중에 떠서 출력됨 (서포트 179cm²)보강대 제거. 실린 무게가 약 200g이라 4mm 판으로 충분해결 서포트 2cm²
v5.2STL이 조립 방향이라 슬라이서에서 직접 돌려야 함모든 부품을 출력 방향으로 돌려 다시 저장해결
v5.2캐스터 구멍 38×28mm가 추정값이었고 실제(스캔 54×24mm)와 다름. M5×10이 너트까지 닿지 않음예전 구멍을 메우고 54×24mm 긴 구멍을 냄. 윗면에 M5 너트 홈(4mm)실측 필요 스캔 오차 ±1.5mm
v5.1보조배터리 USB-A 앞에서 덮개 벽까지 약 2cm라 파이 전원 플러그가 안 들어감덮개 앞 왼쪽에 바닥부터 트인 창해결 플러그 간섭 0건
v5.0덮개 출력이 어려움(서포트 131cm²), 충전할 때 불편, 차 모양이 안 남지붕이 평평한 들어 올림 덮개로 교체. 핀 4개, 볼트 없음해결 서포트 8cm², 들어 올림 간섭 0건
