# 둥근 몸체·조립 검토 v2

2026-10-29 / 기기 A. 기존 v1을 보존하고 별도 모델을 생성했다.

## 포함한 구조
- 둥근 모서리 바닥판과 낮은 테두리, 배터리 측면 받침.
- 30mm 지지대 위 상부 선반과 라즈베리파이 측면 받침.
- 하부 모터 분할 받침, 캐스터 보강판, 드라이버 받침.
- 전방 센서 테두리 및 카메라 받침. 카메라 본체는 미포함.

## 조립 구상
1. 바닥판 아래 모터 받침·캐스터 보강판을 설치하고 휠과 축을 결합한다.
2. 하부에 배터리와 드라이버를 놓는다. 배터리 탈락 방지 스트랩과 배선 경로는 다음 설계에서 추가한다.
3. 지지대 4개 위에 선반을 설치하고 라즈베리파이를 고정한다.
4. 전방 센서와 카메라를 설치하고 배선·시야·회전 간섭을 확인한다.

## 확정 전 사항
이 파일은 구조·배치 판단용이며 출력용이 아니다. 바닥판 두께 4mm, 선반 두께 4mm, 모터 받침과 카메라 받침 크기는 AI의 형상 제안이다. 체결 구멍·나사산·정확한 조립 공차는 아직 모델링하지 않았다. 은색 볼트는 체결 관계를 설명하는 기호이며, 보이는 돌출 길이는 조립 완료 상태를 뜻하지 않는다.

실물과 대조할 항목: 모터 지름 및 축 중심/돌출 길이, 커플링 깊이, 캐스터 장착 구멍 간격과 회전 범위, 보드별 구멍 위치, 카메라 접힌 받침 외곽·볼트 위치·체결 깊이, 지지대 수나사 돌출 길이와 암나사 깊이. 기존 STL의 단위와 스캔 변형도 대조해야 한다. 프린터 출력 크기·재료는 사용자가 추후 확인한다.

6면도와 조립 프리뷰는 동일한 Blender 형상에서 렌더했다. 분해도에서는 부품을 설명 목적으로 이동했고 저장된 모델은 조립 위치로 복원했다. 실제 조립·주행·강도·출력 검증은 수행하지 않았다.
