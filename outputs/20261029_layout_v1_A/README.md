## 반영 내용

- 학교 부품 STL 6종. 바퀴와 모터는 각각 복제하여 2개 배치. 오른쪽 바퀴는 반대 손잡이 형상을 새로 만든 것이 아니므로 좌우 롤러 방향은 검증 대상이다.
- 후방 구동륜, 전방 캐스터, 중앙 하부 배터리 2개, 보조배터리 위쪽 라즈베리 STL, 후방 드라이버 외곽 상자 배치.
- 드라이버는 제품 치수 43×43×27mm 상자. 센서는 알려진 45×21mm 기판 면만 표시. 카메라는 외형 크기를 만들지 않고 프리뷰 설명에 전방 상부 예정 위치를 표시.
- 추가 수업 이미지의 바퀴 지름 96mm와 캐스터 높이 62mm 반영. 스캔의 원시 외곽은 각각 약 97.64mm, 74.48mm이므로 균일 배율로 표시 치수에 맞춘 참고 형상이다. 이 보정이 실제 구멍·장착면까지 정확하다는 의미는 아니다. 다른 STL은 원시 단위를 임시 mm로 해석했으며 실물 대조 필요.
- 카메라 M6×20, 지지대 M4×30 및 체결용 M4×20, 캐스터 M5×10+M5 너트, 휠 M4×12, 모터/커플링 관련 M3×8은 수업 표기 기록. 실제 나사산/조립 위치는 따로 확인한다.
- 바닥판·선반·브래킷·구멍은 아직 만들지 않았다. 배치 좌표와 높이는 검토안이다. 부품이 공중에 보이는 것은 고정 구조가 없는 현재 단계 때문이다. 프린터 제약을 반영하지 않았으며 출력하면 안 된다.
- 배치 외곽 약 240×293×119mm는 현재 참고 형상의 임시 배치 결과이며 확정 차체 치수가 아니다. 스캔 형상과 배치 방향·간격 수정에 따라 달라진다. 폭 30cm 도로 통과/회전 검증은 하지 않았다.

## 실물로 확인해야 할 우선 항목

1. 카메라 본체와 접은 받침의 가로·세로·높이, 받침 밑면 체결 위치, 실제 나사 규격과 사용 가능한 체결 깊이. 수업 제공 볼트 M6×20을 기록하되 나사 구멍 자체의 규격/깊이를 확정하지 않는다.
2. 캐스터 장착판의 가로·세로, 구멍 중심 간격과 지름, 회전축에서 바퀴/포크가 가장 멀리 나가는 거리. 높이 62mm는 이미 자료에 있으므로 전체를 새로 측정할 필요는 없지만 STL과 차이가 커 장착면 기준 높이는 대조한다.
3. 모터 축 중심에서 받침 면까지 높이, 실제 사용할 고정 위치/구멍과 커플링 조립 후 휠 안쪽 면까지 거리. 스캔만으로 축·볼트 정렬을 결정하지 않는다.
4. 라즈베리 제공품(냉각팬/방열판 포함)의 외곽과 고정 구멍, 배터리 2개의 외곽을 STL과 대조. 배터리 단자·케이블 돌출과 플러그 분리 공간 확인. 보드 STL은 실제 사진의 팬을 포함한 상세 형상으로 간주하지 않는다.
5. 센서 돌출 깊이·고정 구멍, 드라이버 고정 구멍 중심 간격/지름은 상세 도면으로 더 확인하고 없으면 실측. 외형 45×21 및 43×43×27을 다시 묻지 않는다.

사용자가 실물 부품을 보유하는지는 아직 답변되지 않았다. 위 값 전부를 한 번에 요구하지 않고 해당 고정 구조 설계 전에 필요한 항목부터 확인한다.

Blender 렌더 10장과 합성 PNG 2장을 생성했으며 합성 이미지에서 6개 시점과 층별 분리 상태·한글 라벨을 눈으로 확인했다. Blender 파일을 다시 열어 전체가 보이는 초기 시점을 저장했다. 간섭 계산·구멍·강도·주행·실물 조립·프린터 출력 검증은 수행하지 않았다.
